# 🛒 RetailIQ – AI-Powered Retail Intelligence Platform

## 📖 Overview

RetailIQ is an end-to-end AI-powered retail intelligence platform developed using Machine Learning, Deep Learning, and Generative AI. It combines multiple AI applications into a single interactive Streamlit interface, allowing users to forecast sales, receive personalized product recommendations, classify retail product images, and interact with an AI assistant.

This project demonstrates the complete AI workflow from model development to deployment through an easy-to-use web application.

---

## 🚀 Features

- 📈 Sales Forecasting using XGBoost
- 🛒 Product Recommendation using Artificial Neural Networks (ANN)
- 🖼️ Product Image Classification using MobileNetV2
- 🤖 AI Assistant powered by FAISS and Google Gemini
- Interactive Streamlit Dashboard
- User-friendly Interface

## 📂 Project Modules

### 📈 Sales Forecasting
Predict future retail sales using machine learning.

### 🛒 Product Recommendation
Recommend products based on customer purchase history.

### 🖼️ Product Classification
Classify retail products from uploaded images using MobileNetV2.

### 🤖 AI Assistant
Answer project-related questions using Retrieval-Augmented Generation (RAG) with FAISS and Google Gemini.
